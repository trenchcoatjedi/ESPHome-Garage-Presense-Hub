# ESPHome-Garage-Presense-Hub
ESPHome based tracking hub for 2 cars and BLE devices; ideal for garage ceiling mount installations. BOM: [DOIT ESP32 DEVKIT V1](https://www.espboards.dev/esp32/esp32doit-devkit-v1/), 2 x [HC-SR04 Ultrasonic modules](https://www.sparkfun.com/ultrasonic-distance-sensor-hc-sr04.html), 2 x cheap [iTag bluetooth trackers from AliExpress](https://www.aliexpress.us/item/3256808320686272.html) <br/>
Paste-and-go configuration for ESPHome that includes nightly battery checks and logic to silence the disconnect beeping (note: these iTags have numerous variants; some do not allow this disconnect beeping to be silenced). Buttons are provided to manually start scans if needed to debug. Battery levels checked on boot and then daily to maximize iTag battery life. BLE presence timeout is 360s to match these iTags; this will need to be adjusted for a different use case. The config.yaml includes a full pin schema for the HC-SR04 Ultrasonic modules, the distance in the lambdas must be updated to suit the use case and installation after measuring distance to the parked car. Encryption keys and BLE MAC addresses also need to be added for a fully working config.
